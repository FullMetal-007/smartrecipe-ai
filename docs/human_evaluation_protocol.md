# Human evaluation protocol

1. Use the same fixed test requests and show evaluators the selected output from each experimental version in randomised order where practical.
2. Ask evaluators to rate each output from 1 (very poor) to 5 (excellent) for: relevance to the request, satisfaction of explicit constraints, practical usefulness, and likelihood of preparing the recipe.
3. Ask evaluators to note missing required ingredients, implausible cooking steps, or unsupported claims separately.
4. Do not tell evaluators which version is expected to perform best. If feasible, hide version labels during rating.
5. Record the number of evaluators, their relevant context without unnecessary personal data, the rating date, and any deviations from the protocol.
6. Report individual ratings and aggregate statistics transparently. With a small convenience sample, describe results as exploratory rather than generalisable.
7. Never fill blank ratings with AI-generated estimates or ratings invented by the project author.
